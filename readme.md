# VetCare Panamá

Sistema de gestión para una clínica veterinaria.

## Tecnologías

- Java 25 (Amazon Corretto)
- JavaFX 25
- Maven
- PostgreSQL / Supabase
- JDBC

## Estado actual

**Fase inicial:** configuración del proyecto, estructura Maven y primera ventana JavaFX.

## Ejecución

Para iniciar la aplicación, ejecuta:

```bash
mvn clean javafx:run
```
